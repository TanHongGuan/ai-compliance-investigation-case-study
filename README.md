### Compliance Investigation Swimlane Diagram

Models the post-alert compliance investigation workflow across the Transaction Monitoring System, Compliance Analyst, Compliance Investigation System, and Compliance Manager / Reviewer.

The diagram highlights process responsibilities, decision points, information-request loops, system interactions, and escalation paths.

📄 [View Swimlane Diagram](diagrams/swimlane_diagram.pdf)

### User Story Map

Translates the compliance investigation workflow into user activities, tasks, and product capabilities from the perspective of the Compliance Analyst.

The story map separates capabilities into:

- **Release 1 — MVP:** minimum end-to-end investigation workflow
- **Release 2 — Workflow Improvements:** usability and efficiency enhancements
- **Release 3 — Advanced / Intelligent Features:** extended AI-assisted capabilities

📄 [View User Story Map](diagrams/user_story_map.pdf)
